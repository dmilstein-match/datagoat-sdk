# Security

Report a vulnerability to support@datagoat.io with "security" in the subject. Please do not open a
public issue for it. We acknowledge within two working days.

In scope: these clients, the Verdict verifiers, and the service at `api.datagoat.io`. A Verdict that
`verify_offline` / `verifyOffline` reports `valid` but that Datagoat did not issue is in scope and
urgent.

Never include an API key (`dgk_live_…`) in a report; revoke any key you have exposed at
https://datagoat.io/keys.
